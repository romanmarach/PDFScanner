Privacy

Privacy note

PDFScanner is built to process documents for the current request, not to keep a document history.

Uploads

Temporary processing

Uploaded files are temporarily saved on the server while your request is processed, then deleted after processing finishes or fails.

For scanned PDFs, rendered page images are created in temporary folders for OCR and removed after OCR completes.

Storage

No document accounts

This app does not create user accounts and does not intentionally store uploaded documents, extracted text, explanations, summaries, or JSON/PDF downloads.

Downloads are generated in your browser from the result currently shown on the page.

AI features

OpenAI processing

Text-only extraction runs locally. When you use Explain or Analyze, extracted document text is sent to OpenAI to generate the explanation, summary, classification, or translation.

OpenAI says API data is not used to train its models unless you opt in, but API abuse-monitoring logs may retain customer content for up to 30 days by default. Read OpenAI's current policy on its data controls page.

Operations

Technical metadata

The server may keep ordinary operational logs and rate-limit counters, such as request timing, IP-based rate-limit keys, errors, and security checks. These are used to run and protect the service.

When bot protection is enabled, uploads are verified with Cloudflare Turnstile, which processes technical information about your browser and connection to distinguish people from bots. See Cloudflare's privacy policy.
